# Gemini Usage Guide

> Gemini는 대용량 컨텍스트 처리와 문서 분석에 최적화된 보조 AI 모델입니다.
> 전체 코드베이스 분석, 자동 문서화, 빠른 생성 작업에 사용합니다.

---

## 역할 정의

Gemini는 다음 작업에 우선 사용합니다:

| 작업 유형 | 구체적인 예시 |
|----------|-------------|
| 대용량 컨텍스트 분석 | 전체 코드베이스 파악, 여러 파일 동시 분석 |
| 문서 자동화 | API 문서 생성, JSDoc 작성, README 생성 |
| 코드 리뷰 요약 | 대규모 PR의 변경사항 요약 |
| 저비용 생성 | 간단한 설명, 예시 코드, 빠른 프로토타이핑 |
| 비교 분석 | 라이브러리 옵션 비교, 마이그레이션 경로 분석 |
| 번역 / 현지화 | 다국어 문자열, i18n 관련 작업 |

---

## 대용량 컨텍스트 활용법

Gemini의 가장 강력한 기능은 긴 컨텍스트 처리입니다.

### 전체 코드베이스 분석 프롬프트

```markdown
# 프로젝트 분석 요청

다음 파일들을 분석하고 [목적]을 수행해주세요:

[파일 1 내용]
---
[파일 2 내용]
---
[파일 3 내용]

## 요청 사항
1. 현재 레이어 의존성 위반 사항 파악
2. 중복 코드 패턴 식별
3. 개선 우선순위 제안
```

### 문서 자동 생성 프롬프트

```markdown
# API 문서 생성

다음 라우터 파일로부터 OpenAPI 3.0 스펙을 생성해주세요:

[라우터 코드]

## 요구사항
- 각 엔드포인트의 request/response 스키마 포함
- 에러 코드 명세 포함
- 한국어 설명
```

## Gemini를 쓰지 않아야 할 때

| 상황 | 대신 사용 |
|------|----------|
| 아키텍처 설계 및 결정 | Claude |
| 복잡한 디버깅 | Claude |
| 타입 시스템 설계 | Claude |
| 단순 CRUD 코드 생성 | Codex |
| 단위 테스트 작성 | Codex |

## 비용 최적화 가이드

Gemini는 대용량/저비용 작업에 적합합니다:

```
고비용 작업 (Claude 사용)
└── 복잡한 설계 논의, 심층 디버깅

중비용 작업 (Gemini 사용)
└── 코드 분석, 문서화, 비교 분석

저비용 작업 (Codex 사용)
└── 보일러플레이트, 단순 CRUD, 테스트
```
