# 디자인 캔버스 대조표

디자인 캔버스(Gangneung Tourism v3)를 실제로 렌더해 화면별로 구현과 맞대본
기록이다. 색 토큰·폰트는 앞서 값 단위로 일치를 확인했으므로 여기서는 다루지
않는다. 이 문서가 다루는 것은 배치 구조와 구성 요소다.

캡처 방법은 `scripts/canvas-probe.mjs`. 캔버스 HTML을 정적 서버로 띄우고
Playwright로 눌러본 뒤 스크린샷과 렌더 후 DOM 개요를 받는다.

```sh
python3 -m http.server 3222 --directory <캔버스 html 폴더>
cd apps/web
node ../../scripts/canvas-probe.mjs --screen 안내 --out /tmp/probe/canvas
node ../../scripts/canvas-probe.mjs --url https://on-gang-reung-web.vercel.app \
  --screen 안내 --out /tmp/probe/impl
```

## 홈 히어로

캔버스는 전체화면 하늘·바다 그라데이션 위에 3D 오브제와 글래스 카드 두 장을
얹는다. 구현은 배경 일러스트를 직접 그려 넣었다.

- 캔버스 중앙에 `hero3dRef` 캔버스로 3D 커피잔이 돌아간다. 구현에는 없다
- 캔버스 우상단에 날씨 글래스 카드가 있다 — `동해중부 연안 / 맑음 / 24° /
체감 26° / 파고 0.8m / 날씨 상세 보기 →`. 구현에는 이 카드가 통째로 없다
- 캔버스는 인기 검색어를 그 아래 별도 글래스 카드로 묶는다. 구현은 하단에
  흩어 놓았다
- 캔버스 배경은 부드러운 그라데이션뿐이다. 구현은 산 실루엣·태양 원·구름을
  도형으로 그려 인상이 다르다

## 홈 본문

섹션 순서와 문구는 일치한다.

- 레일 3종(해변·먹거리·인기), 축제 섹션, 야경 마감 섹션 순서 동일
- 제목 문구도 캔버스 그대로다 — `파도 소리를 기준으로 골라봐요`,
  `뭐 먹으러 가볼래요?`, `요즘 뭐가 핫한지 둘러봐요`,
  `지금 뭐가 열리고 있는지 볼까요?`
- 야경 섹션의 별 반짝임 캔버스는 `StarField`로 구현 완료
- 후기 카루셀은 캔버스에 대응물이 보이지 않는다. 구현 쪽 추가분이다

## 안내

권역 선택과 하위 섹션이라는 골격은 같지만, 섹션 머리 부분의 무게가 다르다.

- 캔버스는 각 섹션에 번호와 영문 라벨을 달고 문장형 제목을 쓴다
  - `01 — WEATHER` / 오늘의 바다와 하늘
  - `02 — TRANSPORT` / 렌트를 할지, 기차를 예매할지 정해봐요
  - `03 — STAY` / 어디서 묵을지 골라봐요
  - `04 — PARKING` / 차는 어디에 둘까요?
  - `05 — EATS` / 언제 열고 얼마나 기다리는지 알아봐요
  - `06 — FESTIVAL` / 기간이 정해진 것들부터 볼까요?
- 구현은 `날씨` `교통` `숙박` `주차장` `먹거리` `축제`처럼 단어 하나로 끝난다.
  번호도 영문 라벨도 문장형 제목도 없다
- 구현에는 `안내소` `무장애` `회화` 세 섹션이 더 있다. CHANGELOG 기준으로
  과거 세션이 의도적으로 되살린 것이므로 제거 대상이 아니다
- 권역 안내 문구가 다르다. 캔버스는 `권역을 고르면 아래 네 가지가 모두 그
권역 기준으로 바뀝니다`, 구현은 다섯 가지를 나열한다

## 테마 목록

카드 형태가 근본적으로 다르다.

- 캔버스: 4열 그리드. 카드마다 사진 슬롯이 위에 크게 올라가고 그 아래
  영문 라벨 · 제목 · 설명 · 태그 칩이 따라온다. 배경은 밝은 편집 지면
- 구현: 3열 그리드. 카드가 통짜 그라데이션 블록(남색·갈색·초록)이고 동심원
  무늬와 `01`~`08` 번호가 얹힌다. 글자는 블록 안에 들어가고 화살표가 붙는다
- 제목 문구도 다르다
  - 캔버스: `무엇을 하고 싶은지로 골라볼까요?` / 지역이 아니라 취향으로
    묶었습니다. 여덟 개 다 같은 무게입니다.
  - 구현: `무엇을 보러 갈지부터 고르기` / 권역이 아니라 주제로 묶은 코스입니다…
- 캔버스 카드에는 번호가 없다. 여덟 개가 같은 무게라는 설명과 맞물린다

> CAUTION: 구현 쪽 카드는 최근 직접 만든 것으로 보인다. 캔버스로 되돌리면
> 그 작업을 버리게 되므로 먼저 확인이 필요하다.

## 마이페이지

메뉴 골격은 비슷하나 스탬프의 성격이 다르다.

- 제목이 다르다. 캔버스는 `05 — MY PAGE` / 마이페이지, 구현은 `MY` / 내 강릉
- 스탬프 대상이 다르다
  - 캔버스: 큐레이션한 명소 8곳. 각 카드에 스티커 이름(`경포대 누각`,
    `커피콩`, `은하수`), 장소명, 행정동, 상태(`방문 완료` / `탭해서 체크인`)
  - 구현: DB의 관광지 38곳 전체. 이름과 `위치 확인 필요` · `찍기` 버튼
- 캔버스에는 `지도로 보기` 버튼이 있다. 구현에는 없다
- 캔버스는 탭으로 체크인하는 흐름이다. 구현은 `현재 위치로 확인` 버튼을 눌러
  500m 반경을 판정한다. 구현 쪽이 실제 동작이 있는 대신 캔버스의 편집된
  스탬프 랠리 성격은 사라졌다
- 구현 메뉴에 `약관 · 정책` `설정`이 더 있다
