# 003. AI 멀티 모델 협업 전략

날짜: 2026-06-27
상태: Accepted

## 배경 (Context)

AI 코딩 도구를 단일 모델에 의존하면 비용, 컨텍스트 한계, 특화 성능의 한계가 있습니다.
Claude, Gemini, Codex는 각각 강점이 다릅니다.

## 결정 (Decision)

작업 유형에 따라 AI 모델을 분리해서 사용합니다:

- Claude: 아키텍처 설계, 복잡한 리팩터링, 디버깅 (기본 모델)
- Gemini: 대용량 컨텍스트 분석, 문서화
- Codex: 보일러플레이트, 단순 CRUD, 테스트 생성

.ai/ 디렉터리에 모델별 컨텍스트 파일을 유지하고,
scripts/switch_model.sh로 빠르게 전환합니다.

## 결과 (Consequences)

긍정적:
- 작업 유형에 최적화된 모델 사용으로 품질 향상
- 비용 최적화 (단순 작업은 저비용 모델 활용)

부정적:
- 모델 전환 시 컨텍스트 재설정 필요
- 팀원이 세 가지 모델 특성을 모두 알아야 함
