## 검증

- `pnpm verify`: 7/7 성공, 캐시 없이 실행. API 122개, 웹 129개.
- API 커버리지 99.22%, 웹 라인 커버리지 52.67%.
- `pnpm --filter web build`: 성공.
- Playwright: 기존 13개 + 신규 6개. API 장애 중 이동·복구, 부분 실패 격리,
  320/390/768/1280px 안내 화면의 라이트·다크 가로 넘침 검증.
- 생성된 OpenAPI/TypeScript를 재생성한 뒤 SHA-256 비교: drift 없음.
- SQLite 임시 DB에서 실제 0001~0008 업그레이드, 0007 데이터 변환,
  enum 기본값의 ORM 조회, metadata 비교, 다운그레이드·재업그레이드 성공.
- PostgreSQL용 0001~0008 SQL 오프라인 생성 성공. 실제 PostgreSQL 서버에 적용한 검증은 아니다.
- 정적 import 점검에서 FSD 상위 레이어·동일 레이어 교차 의존 0건.

## 마이그레이션 적용

0008은 기존 enum 데이터를 변환한다. 구버전 API는 대문자 저장값을 기대하므로,
구버전 워커를 중단한 뒤 마이그레이션하고 새 버전을 시작해야 한다.

```sh
cd apps/api
uv run alembic upgrade head
```

이번 작업에서는 임시 DB에만 적용했다. 개발·운영 DB에는 적용하지 않았다.
롤백은 API 워커를 중단한 상태에서 `alembic downgrade 0007`과 구버전 코드 복귀를 함께 수행한다.
이 변경은 구버전·신버전을 혼합 실행하는 무중단 배포용 이중 읽기 구현이 아니다.

## 남은 외부 연동 및 검증 범위

- 날씨·교통 실시간 연동, i18n, 오프라인 등은 기존 세션에서 제외한 H단계 그대로다.
  날씨 숫자는 명시적으로 예시로 표시한다.
- 축제 진행 여부·안내 콘텐츠·공지·정책은 기존 편집/시드 데이터다.
  실제 날짜에 따른 자동 갱신이나 콘텐츠 사실 확인까지 수행한 것은 아니다.
- AI 실제 유료 호출, TourAPI 실서비스 수집, PostgreSQL 실서버 테스트는 수행하지 않았다.
- 비회원 AI 코스는 기존 공개 단건 조회 동작을 유지한다. 회원 코스는 소유자만 조회한다.
- AI 기본 모델명은 [Anthropic 공식 모델 안내](https://platform.claude.com/docs/en/models/overview)를
  확인했고 기존 값을 유지했다. 이제 환경설정으로 변경할 수 있다.
